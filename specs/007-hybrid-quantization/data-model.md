# Data Model: Per-Path Hybrid Quantization

## Entities

### QuantizationProfile
Represents a per-path hybrid quantization configuration specifying different bit-widths for attention vs expert layers.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| version | string | Yes | Semver version of profile schema (e.g., "1.0.0") |
| preset_name | string | No | Human-readable preset name (e.g., "tq3a-tq2e-g32") |
| attention_bits | integer | Yes | Bit-width for attention layers (2-8, default: 3) |
| expert_bits | integer | Yes | Bit-width for expert layers (2-8, default: 2) |
| group_size | integer | Yes | Quantization group size (16, 32, 64, 128; default: 32) |
| calibration_method | string | Yes | Calibration method: "none" or "lloyd-max" (default: "none") |
| model_patterns | array[string] | Yes | Regex patterns to match model architectures (e.g., ".*nemotron.*120b.*") |
| calibration_data_path | string | No | Path to calibration dataset for Lloyd-Max optimization |

**Example**:
```yaml
quantization_profiles:
  tq3a-tq2e-g32:
    version: "1.0.0"
    preset_name: "tq3a-tq2e-g32"
    attention_bits: 3
    expert_bits: 2
    group_size: 32
    calibration_method: none
    model_patterns:
      - ".*nemotron.*120b.*"
      - ".*120b.*moe.*"
```

### ModelArchitecture
In-memory representation of model structure including layer types for per-path quantization.

| Field | Type | Description |
|-------|------|-------------|
| architecture_name | string | Model architecture name (e.g., "Nemotron-3-Super-120B-A12B") |
| total_params | integer | Total parameter count |
| active_params | integer | Active parameters for MoE models (e.g., 12B for A12B models) |
| layer_types | array[string] | List of layer type identifiers (e.g., ["attention", "mlp", "expert_router", "expert_0"]) |
| expert_count | integer | Number of experts (0 for non-MoE models) |
| is_moe | boolean | True for mixture-of-experts architectures |
| detected_expert_layers | array[string] | Layer names identified as expert layers |
| detected_attention_layers | array[string] | Layer names identified as attention layers |

**Detection Rules**:
- Expert layers: Match patterns `.*expert.*`, `.*router.*`, `.*moe.*` in layer names
- Attention layers: Match patterns `.*attention.*`, `.*self_attn.*`, `.*q_proj.*`, `.*k_proj.*`, `.*v_proj.*`
- MoE detection: `expert_count > 0` OR `is_moe == True` in model config

### CalibrationDataset
Metadata and reference to calibration data for Lloyd-Max codebook optimization.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| dataset_id | string | Yes | UUID for the dataset |
| source | string | Yes | Origin description (e.g., "WikiText-103", "custom-conversations") |
| format | string | Yes | Data format: "json", "numpy", or "text" |
| sample_count | integer | Yes | Number of calibration samples |
| data_path | string | Yes | Filesystem path to calibration data |
| created_at | string | Yes | ISO 8601 timestamp of dataset creation |
| checksum | string | No | Optional MD5/SHA256 checksum for integrity verification |

**Supported Formats**:
- **JSON**: Tokenized text as array of token ID arrays `[ [101, 202, ...], ... ]`
- **Numpy**: `.npy` file with shape `(sample_count, sequence_length)` containing token IDs
- **Text**: Plain text file, will be tokenized using model's tokenizer

### Codebook
Optimized quantization lookup tables generated by Lloyd-Max algorithm.

| Field | Type | Description |
|-------|------|-------------|
| codebook_id | string | UUID for the codebook |
| algorithm_version | string | Algorithm version (e.g., "V3" from sharpner/turboquant-mlx) |
| bits | integer | Quantization bit-width this codebook applies to (2-8) |
| group_size | integer | Group size used for this codebook (16, 32, 64, 128) |
| model_layers | array[string] | Layer names this codebook applies to |
| binary_path | string | Path to serialized MLX array file (`.mlx` or `.npy` format) |
| generated_at | string | ISO 8601 timestamp of codebook generation |
| calibration_dataset_id | string | UUID of calibration dataset used (foreign key to CalibrationDataset) |
| perplexity_improvement | float | Measured perplexity improvement vs standard quantization (percentage) |

**Storage**: Codebooks stored in `scripts/wrapper-config/codebooks/{codebook_id}.mlx`

## Relationships

```
QuantizationProfile (1) ────> (0..n) ModelArchitecture [via model_patterns regex match]
QuantizationProfile (1) ────> (0..1) CalibrationDataset [via calibration_data_path]
CalibrationDataset (1) ────> (0..n) Codebook [one per layer type/bits combination]
Codebook (1) ────> (0..n) ModelArchitecture.layers [applied to specific layers]
```

## State Transitions

### Quantization Profile Application
```
[Profile Selected] ──> [Validate Profile] ──> [Detect Model Architecture] ──> [Match Layers] ──> [Apply Quantization] ──> [Server Ready]
       │                    │
       │                    └──> [Validation Failed] ──> [Return Error ERR-001/002/006]
       └──> [Profile Not Found] ──> [Return Error]
```

### Lloyd-Max Calibration Flow
```
[CalibrationDataset Provided] ──> [Load Data] ──> [Validate Format] ──> [Run V3 Algorithm] ──> [Generate Codebooks] ──> [Save .mlx Files]
                                    │                    │
                                    └──> [Format Error] ──> [Return Error ERR-003]
                                    └──> [Algorithm Failed] ──> [Return Error, Use Standard Quantization]
```

### Model Architecture Detection
```
[Model Load Start] ──> [Read config.json] ──> [Check MoE Fields] ──> [Inspect Layer Names] ──> [Classify Layers] ──> [Return ModelArchitecture]
                            │                         │                        │
                            └──> [Config Missing] ──> [Use Pattern Matching from Profile]
                            └──> [Not MoE] ──> [expert_count = 0, is_moe = False]
                            └──> [No Layer Info] ──> [Apply Default Attention-Only Quantization]
```

## File Locations

| Artifact | Path | Format |
|----------|------|--------|
| Quantization Profiles | `scripts/wrapper-config/profiles.yaml` | YAML |
| Calibration Datasets | User-provided path (metadata in memory) | JSON/Numpy/Text |
| Generated Codebooks | `scripts/wrapper-config/codebooks/*.mlx` | Binary MLX |

| Quantization Logic | `scripts/quantization/` (new module) | Python |

## Validation Rules

### QuantizationProfile Validation
1. **Bit-width Range** (Critical): `attention_bits` and `expert_bits` must be between 2 and 8 (ERR-001)
2. **Group Size** (Critical): `group_size` must be one of [16, 32, 64, 128] (ERR-006)
3. **Calibration Method** (Warning): If `calibration_method` is "lloyd-max", `calibration_data_path` should be provided
4. **Model Patterns** (Info): At least one pattern recommended for automatic profile matching

### ModelArchitecture Validation
1. **Layer Detection** (Critical): Must identify at least attention layers for quantization (ERR-002)
2. **MoE Consistency** (Warning): If `is_moe == True`, expect `expert_count > 0`
3. **Expert Layer Match** (Critical): For hybrid quantization, expert layers must be detected when `expert_bits` specified

### CalibrationDataset Validation
1. **Format Support** (Critical): `format` must be "json", "numpy", or "text" (ERR-003)
2. **Path Existence** (Critical): `data_path` must exist and be readable
3. **Sample Count** (Warning): Less than 100 samples may produce poor codebooks
